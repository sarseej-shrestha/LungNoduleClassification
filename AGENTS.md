# Lung Nodule CAD System

This is a medical imaging project for lung nodule detection using a 3-branch ResNet-18 architecture with Uncertainty Estimation.

## Project Type
- Python-based medical imaging / deep learning project
- Data: `annotations.csv` contains nodule coordinates (seriesuid, coordX, coordY, coordZ, diameter_mm)
- `subset0.zip` contains DICOM image data

## Architecture
- 3-branch ResNet-18 backbone
- Uncertainty Estimation branch for confidence scores
